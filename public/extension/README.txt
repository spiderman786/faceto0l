Faceto0l Chrome extension — v0.3.0 (Foundation E)
=================================================

Download:
  https://faceto0l.vercel.app/extension/faceto0l-extension.zip

Install (Chrome / Edge):
1. Download and unzip faceto0l-extension.zip
2. Open chrome://extensions (or edge://extensions)
3. Turn on Developer mode
4. Click "Load unpacked"
5. Select the unzipped "faceto0l-extension" folder (must show version 0.3.0)
6. Open https://faceto0l.vercel.app/dashboard in THIS browser
7. Log into Facebook in the same browser

Grab + schedule:
1. Open a TikTok / Instagram / YouTube profile tab
2. In Faceto0l tool → Grab Videos/Posts (or paste links)
3. Select pages → Interval or Daily Window → Start schedule
4. Keep the dashboard tab open while the schedule runs

Each schedule slot opens the source URL + Facebook page (caption copied when allowed).
Fully automated Meta composer publish is the next hardening step.
