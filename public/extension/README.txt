Faceto0l Chrome extension — v0.3.1 (Foundation E · auto composer)
=================================================================

Download:
  https://faceto0l.vercel.app/extension/faceto0l-extension.zip

Install / update:
1. Download + unzip
2. chrome://extensions → Remove old Faceto0l → Load unpacked
3. Version must show 0.3.1

Flow:
1. Facebook logged in (same Chrome)
2. Open TikTok / IG / YouTube profile → Grab (or paste links)
3. Select FB pages → Interval or Daily Window → Start
4. Keep dashboard open — each slot resolves media, opens page composer,
   attaches file when possible (or pastes caption/link), and tries Post

Notes:
- Large videos may download to Downloads/Faceto0l for manual attach
- Confirm Post if Facebook shows an extra confirmation
- YouTube native MP4 resolve is limited; link/caption post is the fallback
